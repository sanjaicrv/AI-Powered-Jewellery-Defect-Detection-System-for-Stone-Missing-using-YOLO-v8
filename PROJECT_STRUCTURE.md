# Project Folder Structure & File Explanation
**Anomaly Detection in Jewellery (YOLOv8)**

This document provides a detailed overview of the directories and files within the `Anomaly Detection in Jewellery.v1i.yolov8` project workspace. This project uses the Ultralytics YOLOv8 object detection model (specifically `yolov8n` Nano) to detect anomalies—specifically **missing gems** in jewellery.

## 📁 Detailed Folder Explanations

### 1. `train/`, `valid/`, & `test/` (Dataset Splits)
These folders contain the dataset splits exported from Roboflow:
* **`images/`**: Contains the source image files (JPEG, PNG, etc.).
* **`labels/`**: Contains matching text files (having the exact same filename as the image, but with `.txt` extension) specifying the object class and normalized bounding box coordinates.
* **`labels.cache`**: A binary cache file generated by Ultralytics when starting training or validation. It speeds up the data loading phase in future runs.

### 2. `runs/` (Training & Inference Outputs)
This folder holds outputs automatically generated by the YOLO framework.
* **`runs/detect/train/`**: Created when running `train.py`.
  * **`weights/best.pt`**: The trained model weights with the highest mean Average Precision (mAP) on the validation set. **Use this file for deployments or predictions**.
  * **`weights/last.pt`**: The model state at the final epoch. Useful if you want to resume training.
  * **Diagnostic charts**: Files like `results.png`, `confusion_matrix.png`, `F1_curve.png`, `PR_curve.png`, etc., display validation metrics, losses, and class detection accuracy.
* **`runs/detect/predict/`**: Created when running `predict.py`. It holds copy of the test images with bounding boxes overlayed on any detected defects.

### 3. `venv/` (Python Virtual Environment)
This is a standard virtual environment containing the python executable and project dependencies. Running instructions within this virtual environment prevents version conflicts with your system-wide Python.

  Lists the Python libraries needed to run the project. This includes `torch` (PyTorch for deep learning), `ultralytics` (YOLOv8 framework), `opencv-python` (live camera preview / image rendering), `pillow` (image checking), `numpy`, `matplotlib`, and helper libraries.
* **[.gitignore](file:///d:/Final%20year%20project/Anomaly%20Detection%20in%20Jewellery.v1i.yolov8/.gitignore)**:
  Instructs git to ignore local environment files (like `venv/`), auto-generated run logs (`runs/`), cache files (`.cache`), and heavy binary weight files (`.pt`) so they do not clutter repository commits.

### ⚙️ Python Scripts
* **[restore_and_convert.py](file:///d:/Final%20year%20project/Anomaly%20Detection%20in%20Jewellery.v1i.yolov8/restore_and_convert.py)**:
  This script is used because the original Roboflow export annotated objects with polygon coordinates (YOLOv8 segmentation format). Because we are training a standard object detection model, this script extracts label data from the backup ZIP file, calculates the bounding box coordinates (min/max bounding values), formats it for YOLOv8 detection, and saves the corrected `.txt` labels to the dataset folders.
* **[validate_dataset.py](file:///d:/Final%20year%20project/Anomaly%20Detection%20in%20Jewellery.v1i.yolov8/validate_dataset.py)**:
  Validates image integrity and label formats. It checks for:
  1. Corrupt image files.
  2. Duplicate images (via MD5 hashing).
  3. Bounding box coordinates out of bounds (and automatically clips values between 0.0 and 1.0).
  4. Class IDs that do not match the dataset config.
  5. Label files that exist without matching images (orphaned annotations), which it automatically deletes to prevent training errors.
* **[train.py](file:///d:/Final%20year%20project/Anomaly%20Detection%20in%20Jewellery.v1i.yolov8/train.py)**:
  The entry point for training the YOLOv8 model. It checks for GPU availability, loads the pre-trained weights (`yolov8n.pt`), configures specific hyperparameters optimized for a 4GB VRAM GPU (like early stopping `patience=20`, `workers=2` to prevent Windows multi-processing bugs, and `amp=True` mixed precision), trains the model, and runs a validation script at the end.
* **[predict.py](file:///d:/Final%20year%20project/Anomaly%20Detection%20in%20Jewellery.v1i.yolov8/predict.py)**:
  Loads the trained model (`runs/detect/train/weights/best.pt`) and performs batch inference on images inside the `test/images` directory. It outputs the detection summary and saves the visual result to `runs/detect/predict/`.
* **[live_preview.py](file:///d:/Final%20year%20project/Anomaly%20Detection%20in%20Jewellery.v1i.yolov8/live_preview.py)**:
  Opens a webcam feed or camera stream, runs real-time inference using the trained weights frame-by-frame, and renders the live feed with boxes drawn over any detected anomalies. Pressing `q` closes the window.

## 🏷️ Annotation Data Format

Inside the `.txt` label files, each line follows the **YOLOv8 Bounding Box Format**:

```text
<class_id> <x_center> <y_center> <width> <height>
```

1. **`<class_id>`**: The integer ID representing the class. In this project, there is only one class: `0` (which corresponds to `missing gem`).
2. **`<x_center>`**: The horizontal center coordinate of the box, divided by the total width of the image (value between `0.0` and `1.0`).
3. **`<y_center>`**: The vertical center coordinate of the box, divided by the total height of the image (value between `0.0` and `1.0`).
4. **`<width>`**: The width of the bounding box, divided by the total width of the image (value between `0.0` and `1.0`).
5. **`<height>`**: The height of the bounding box, divided by the total height of the image (value between `0.0` and `1.0`).

Example line:
```text
0 0.485294 0.513235 0.123529 0.147059
```
*(This means: class `0` (missing gem) centered at (48.5%, 51.3%) with a bounding box width of 12.3% and height of 14.7% of the image size)*
